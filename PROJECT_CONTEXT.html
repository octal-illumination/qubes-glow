3. Architecture Summary

KittyGlowEffect tracks kitty windows via windowClass() and draws ONE hardware-blended triangle-fan quad around the frame rect; a GLSL SDF shader (glowshader.cpp) computes per-side soft falloff (v3 — replaced the v2 8-stacked-rect approach). Thickness/radius/active-inactive colors come from kwinrc [Effect-kittyglow], live-reloadable via reconfigureEffect. Damage is widened in prePaintWindow + repaint hooks on geometry/minimize so the halo never smears. Full design: ARCHITECTURE.md.

None. Stateless effect; no persistence beyond kwinrc enable flag.
